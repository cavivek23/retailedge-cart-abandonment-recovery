# RetailEdge Cart Abandonment Recovery

## Technology Stack

- Python 3.12
- FastAPI for HTTP APIs
- SQLAlchemy 2.x ORM
- Pydantic v2 for DTO validation
- PyJWT for JWT handling
- pytest for automated tests
- SQLite for local evaluation; PostgreSQL-compatible ORM patterns

## Scope

This project implements the RetailEdge Cart Abandonment Recovery case study and includes a reviewed Inventory Sync module, technical specification, tests, prompt documentation, architecture notes, and delivery artifacts.

## Local Setup

```text
python -m venv .venv
.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
pytest
```
